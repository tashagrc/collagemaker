# CollageMaker 

A simple iOS app with Storyboard to create a collage images.
This app is to learn RxSwift, especially Observable and Subject. 

The resources is from kodeco RxSwift book, Chapter 4.

## Features
### 1. Page 1: Collage combine
There's an image view to view the collage, a clear button, and a save button. 
### 2. Page 2: Add image
Click the plus button in previous page to select images from gallery. Images added will automatically appended in collage.
